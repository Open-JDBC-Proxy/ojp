# Hard Level Questions

This directory contains hard-level questions for the OJP certification exam.

## Characteristics

**Target Audience**: Advanced users, architects, and contributors  
**Cognitive Level**: Evaluate, Create  
**Time per Question**: 2-4 minutes

## What Hard Questions Test

- Complex scenario analysis
- Architectural design decisions
- Advanced troubleshooting
- Performance optimization
- Custom implementations
- Trade-off evaluation
- Synthesis of multiple concepts

## Usage in Certification

- **Bronze Certification**: 0 hard questions (0% of exam)
- **Silver Certification**: 5 hard questions (12.5% of exam)
- **Gold Certification**: 25 hard questions (50% of exam)

## Quality Standards

All hard questions must:
- Present complex, multi-variable scenarios
- Require expert-level understanding
- Test synthesis and evaluation
- Include realistic production challenges
- Provide in-depth explanations
- Teach advanced concepts

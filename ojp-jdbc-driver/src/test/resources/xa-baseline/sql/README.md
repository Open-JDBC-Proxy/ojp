# XA Baseline Test SQL Scripts

This directory contains SQL initialization scripts for setting up XA support in various databases.

## Scripts

- `oracle-xa-setup.sql` - Oracle XA permissions and configuration (Phase 2)
- `sqlserver-xa-setup.sql` - SQL Server XA stored procedures and permissions (Phase 6)
- `db2-xa-setup.sql` - DB2 XA transaction manager configuration (Phase 7)

Scripts will be added in their respective implementation phases.
